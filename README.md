# E-Commerce Website Manual Testing Project

## Project Overview
This project demonstrates manual software testing skills using demo e-commerce websites. It includes test planning, test case design, functional testing, and bug report documentation.

## Objectives
- Validate login functionality.
- Test product search functionality.
- Verify shopping cart operations.
- Document expected and actual results.
- Understand test execution and defect reporting.

## Websites Tested
- **SauceDemo:** https://www.saucedemo.com/
- **Automation Exercise:** https://automationexercise.com/

## Testing Scope
- Login with valid credentials
- Login with incorrect password
- Login with empty fields
- Search for an existing product
- Search for a non-existing product
- Add a product to the shopping cart
- Remove a product from the shopping cart

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- UI Validation

## Tools Used
- GitHub
- Web Browser
- Markdown
- Manual Testing

- `Test-Plan.md` — Testing objectives, scope, and approach
