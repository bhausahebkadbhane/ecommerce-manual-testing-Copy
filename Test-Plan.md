
# E-Commerce Website - Test Plan

## 1. Project Overview
This project focuses on manual testing of an e-commerce website.

## 2. Objective
To verify that the main features of the website work according to the expected requirements.

## 3. Scope of Testing
- User Registration
- User Login and Logout
- Product Search
- Product Details
- Add to Cart
- Update and Remove Cart Items
- Checkout
- Order Confirmation

## 4. Testing Types
- Functional Testing
- Smoke Testing
- Retesting
- Regression Testing
- Positive Testing
- Negative Testing
- UI Testing

## 5. Test Environment
- Operating System: Windows
- Browser: Google Chrome
- Testing Type: Manual Testing

## 6. Roles and Responsibilities
Tester:
- Understand requirements.
- Prepare and execute test cases.
- Report defects.
- Assign severity and priority recommendations.
- Retest fixed defects.

Developer:
- Investigate reported defects.
- Fix defects.
- Update defect status.

## 7. Entry Criteria
- Application is available for testing.
- Requirements are understood.
- Test environment is ready.

## 8. Exit Criteria
- Planned test cases have been executed.
- Critical defects have been reviewed.
- Test results and known issues are documented.

## 9. Deliverables
- Test Plan
- Test Cases
- Bug Reports
- Defect Life Cycle
- Test Summary Report

## 10. Note
This is a learning project. Actual test results and defects will be recorded only after testing the application.
